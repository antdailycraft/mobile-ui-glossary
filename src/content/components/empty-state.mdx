## 정의

Empty State는 목록이나 화면에 표시할 데이터가 하나도 없을 때 빈 공간 대신 보여 주는 안내입니다. 보통 **그림(아이콘) → 상황 설명 → 행동 버튼** 순서로 구성합니다.

빈 이유는 크게 세 가지이고, 이유마다 안내 내용이 달라야 합니다.

- **처음 사용**: 아직 만든 것이 없는 상태입니다. 첫 항목을 만들도록 안내합니다.
- **검색·필터 결과 없음**: 조건에 맞는 항목이 없는 상태입니다. 조건을 바꾸거나 지우도록 안내합니다.
- **오류**: 불러오기에 실패한 상태입니다. 원인과 다시 시도 방법을 안내합니다.

## 사용하면 좋은 경우

- 새 사용자가 처음 보는 화면에서 **무엇을 할 수 있는지** 알려 주고 첫 행동을 유도할 때
- 검색 결과가 없을 때 "결과 없음"만 보여 주지 않고 **다음 행동**(검색어 지우기, 필터 해제)을 제안할 때
- 네트워크 오류처럼 사용자가 해결할 수 있는 문제를 **다시 시도** 버튼과 함께 알릴 때

## 사용하지 말아야 할 경우

- 데이터를 아직 **불러오는 중**일 때. 이때 "항목이 없습니다"를 보여 주면 잘못된 정보입니다. 로딩 중에는 Skeleton Screen이나 인디케이터를 씁니다.
- 세 가지 이유를 **하나의 문구**로 뭉뚱그릴 때. "데이터가 없습니다"는 사용자가 무엇을 해야 할지 알려 주지 않습니다.
- 그림만 크고 행동 버튼이 없어서 사용자가 **막다른 길**에 서게 될 때
- 화면의 일부 영역만 비었는데 화면 전체를 덮는 큰 빈 상태를 띄울 때. 그 영역 안에 작게 표시합니다.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 공식 컴포넌트 | 없음. 빈 상태는 화면 설계 패턴으로 다룸(Material 2의 Empty states 가이드) | `ContentUnavailableView`(SwiftUI), `UIContentUnavailableConfiguration`(UIKit), iOS 17부터 |
| 기본 구성 | 일러스트·제목·설명·버튼을 앱이 직접 구성 | SF Symbol 아이콘·제목·설명·버튼을 표준 레이아웃으로 제공 |
| 검색 결과 없음 | 앱이 직접 구성 | `ContentUnavailableView.search`로 검색어를 넣은 표준 문구 제공 |

iOS 17부터는 빈 상태를 위한 표준 뷰가 생겨서, 검색 결과 없음 화면을 한 줄로 만들 수 있습니다. Material에는 대응하는 컴포넌트가 없으므로 이 데모처럼 색 역할 토큰과 기존 버튼 스타일로 직접 구성합니다.
