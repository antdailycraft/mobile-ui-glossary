## 정의

Meatball Menu는 점 세 개가 **가로**로 놓인 아이콘(⋯) 버튼입니다. 접시에 미트볼 세 개가 나란히 놓인 모양이라는 데서 붙은 별명입니다. 역할은 Kebab Menu와 같습니다. 화면에 다 넣지 못한 **부가 동작**을 버튼 뒤에 모아 두고, 누르면 메뉴로 펼칩니다.

iOS에서는 SF Symbols의 `ellipsis`나 원 안에 점이 든 `ellipsis.circle` 아이콘을 쓰고, 누르면 **풀다운 메뉴**가 버튼 근처에 펼쳐집니다. 풀다운 메뉴는 둥근 모서리에 항목 오른쪽에 아이콘이 붙고, 삭제처럼 되돌릴 수 없는 항목은 빨간색으로 표시합니다. 웹 서비스에서도 게시물·댓글 옆의 더보기 버튼으로 흔히 씁니다.

## 사용하면 좋은 경우

- iOS 앱의 내비게이션 바나 툴바에 **덜 쓰는 동작**을 모아 둘 때
- 게시물, 댓글, 카드처럼 반복되는 항목마다 **같은 부가 동작**이 있을 때
- 가로로 긴 행이나 카드 모서리에 세로 아이콘보다 가로 아이콘이 더 자연스러울 때

## 사용하지 말아야 할 경우

- Android 앱에서 쓸 때. Material의 표준은 세로 점 세 개(Kebab Menu)입니다.
- 한 화면에서 Kebab과 Meatball을 **섞어 쓸** 때. 같은 의미의 아이콘은 하나로 통일합니다.
- 그 화면의 **핵심 동작**을 숨길 때. 자주 쓰는 동작은 버튼으로 드러냅니다.
- 항목이 많고 설명이 필요할 때. 화면 아래에서 올라오는 Action Sheet가 더 읽기 쉽습니다.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 아이콘 | `more_horiz`가 있지만 표준은 세로 `more_vert` | `ellipsis`, `ellipsis.circle` (⋯) |
| 공식 명칭 | Overflow menu | Pull-down button + Menu |
| 메뉴 모양 | 모서리가 작은 사각형, 아이콘은 라벨 왼쪽 | 모서리가 둥근 반투명 메뉴, 아이콘은 라벨 오른쪽 |
| 파괴적 항목 | 별도 색 규칙 없음 | 빨간색(destructive) 스타일 |
| 길게 누르기 | 별도 규칙 없음 | 항목을 길게 누르면 같은 동작의 컨텍스트 메뉴 |

같은 "더보기"라도 플랫폼마다 아이콘 방향이 다릅니다. Android에서는 세로(⋮), iOS와 많은 웹 서비스에서는 가로(⋯)입니다. 크로스 플랫폼 앱이라면 플랫폼에 맞는 방향을 보여 주는 것이 일반적입니다.
