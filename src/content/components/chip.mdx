## 정의

Chip은 짧은 글자(와 선택적인 아이콘)를 담은 작은 요소입니다. 여러 개를 가로로 나란히 놓고 씁니다. 모양은 비슷하지만 **눌렀을 때의 의미**에 따라 Material Design 3는 네 종류로 나눕니다.

- **Assist chip**: 화면 내용과 관련된 동작을 바로 실행합니다. (예: 길찾기, 공유)
- **Filter chip**: 켜고 끌 수 있으며, 켜진 칩의 조건으로 결과를 거릅니다.
- **Input chip**: 사용자가 입력한 값(검색어, 받는 사람 등)을 칩으로 보여 주며, 삭제할 수 있습니다.
- **Suggestion chip**: 추천 검색어나 빠른 답장처럼 다음에 입력할 만한 값을 제안합니다.

## 사용하면 좋은 경우

- 검색 결과 위에서 **여러 조건을 골라** 거를 때 (filter chip)
- 이메일 받는 사람, 태그처럼 입력한 값을 **하나씩 보고 지울** 수 있어야 할 때 (input chip)
- 화면 내용에 맞는 **바로가기 동작**을 몇 개 제안할 때 (assist, suggestion chip)

## 사용하지 말아야 할 경우

- 화면의 **주요 동작**에 쓸 때. 칩은 눈에 덜 띕니다. 주요 동작은 버튼이나 FAB로 둡니다.
- 서로 배타적인 선택지 2~5개 중 **하나만** 고르게 할 때. Segmented Control이나 라디오 버튼이 의미가 더 분명합니다.
- 칩이 너무 많아 여러 줄로 넘칠 때. 가로 스크롤 한 줄로 두거나, 필터 화면을 따로 만듭니다.
- 한 줄에 서로 다른 종류의 칩을 **섞어** 놓을 때. 무엇을 누르면 어떻게 되는지 예측하기 어렵습니다.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 공식 명칭 | Chip (assist, filter, input, suggestion) | 해당 컴포넌트 없음 |
| 필터 선택 | Filter chip | Segmented Control, 메뉴가 있는 Pull-down button, 토글 |
| 입력값 표시 | Input chip | 검색 필드의 token (`UISearchTextField`), 메일 받는 사람 필드 |
| 모양 | 32dp 높이, 8dp 모서리, 테두리 또는 채움 | 앱이 직접 만드는 캡슐 모양 버튼이 흔함 |

iOS HIG에는 Chip이라는 이름의 컴포넌트가 없습니다. 대신 검색 필드의 token이나 캡슐 모양 버튼으로 비슷한 역할을 합니다. 웹에서는 "태그"나 "필"(pill)이라고도 부릅니다.

**접근성 주의:** Filter chip은 `aria-pressed`로 켜짐 상태를 알려 주고, 색만이 아니라 체크 아이콘으로도 선택 상태를 표시합니다. 칩은 32px로 작으므로, 보이는 크기와 별도로 터치 영역을 44px 이상으로 넓혀 줍니다.
