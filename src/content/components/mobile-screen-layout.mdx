## 화면을 위에서 아래로 읽기

| 위치 | 용어 | 역할 |
|---|---|---|
| 화면 맨 위 | 시스템 상태 바 · Status bar | 운영체제가 시계, 연결 상태, 배터리를 표시합니다. |
| 앱 상단 | 상단 앱 바 · Top app bar | 현재 위치, 뒤로 가기, 화면 작업을 표시합니다. Apple에서는 탐색 중심인 상단 바를 Navigation bar라고도 부릅니다. |
| 상단 또는 본문 시작 | 검색창·필터·화면 내 탭 | 현재 화면에서 보여 줄 내용의 범위를 바꿉니다. 통합 검색에서는 검색창과 필터가 이 영역에 들어갑니다. |
| 가운데 | 본문 · Main content | 메시지, 목록, 문서, 검색 결과처럼 이 화면의 핵심 콘텐츠가 있는 영역입니다. |
| 앱 하단 | 하단 탐색 또는 작업 영역 | Tab bar(Apple)와 Navigation bar(Android)는 주요 화면을 전환합니다. 하단 도구 막대는 현재 화면에 대한 작업을 제공하며, 채팅의 메시지 입력창도 이 위치에 둘 수 있습니다. |
| 화면 맨 아래 | 시스템 탐색 영역 | 운영체제의 홈 제스처나 뒤로 가기 버튼이 있는 영역입니다. 소프트 키보드가 열리면 앱이 사용할 수 있는 높이가 달라질 수 있습니다. |

화면마다 필요한 영역이 달라집니다. 예를 들어 채팅은 **상단 앱 바 → 메시지 목록 → 입력창**, 통합 검색은 **상단 앱 바 → 검색창과 필터 → 결과 목록**으로 구성할 수 있습니다.

## 화면 위로 겹치는 영역

- **오버레이**는 기존 화면 위로 일시적으로 표시되는 영역입니다. 더 보기 메뉴, 다이얼로그, 모달 바텀 시트가 여기에 해당합니다.
- **사이드바·내비게이션 드로어**는 주요 이동 경로를 보여줍니다. 넓은 화면에서는 본문 옆에 두고, 모바일에서는 필요할 때 화면 위에 열 수 있습니다.
- **스낵바**는 저장 완료 같은 짧은 결과를 알려줍니다. 하단에 띄울 때 입력창이나 화면 전환 버튼을 가리지 않도록 배치합니다.

## 안전 영역과 키보드

Apple의 **Safe area**와 Android의 **Window insets**는 상단 상태 바, 화면 잘림, 하단 시스템 탐색 영역 등에 콘텐츠와 조작 버튼이 가리지 않도록 배치할 때 쓰는 기준입니다. Android에서는 키보드가 차지하는 영역을 IME inset으로 확인할 수 있습니다. 검색창과 채팅 입력창이 키보드 위에 남고, 결과와 메시지 목록을 계속 스크롤할 수 있는지 확인합니다.

웹에서는 `main`과 `nav` 같은 HTML 요소로 본문과 탐색 영역을 표시할 수 있습니다. 스크린리더는 이런 주요 영역을 빠르게 이동하는 데 활용합니다.
