## 정의

Hamburger Menu는 가로줄 세 개(☰) 모양의 아이콘 버튼입니다. 빵 사이에 패티가 낀 햄버거처럼 보인다고 해서 붙은 이름입니다. 버튼 자체는 메뉴가 아니라 **숨겨진 내비게이션을 여는 트리거**입니다. 무엇이 열리는지는 플랫폼마다 다릅니다.

- **Material**: 앱 바 왼쪽의 메뉴 아이콘으로, 누르면 Navigation Drawer가 열립니다.
- **웹**: 좁은 화면에서 접힌 상단 메뉴를 펼치는 버튼으로 많이 씁니다. 열리면 아이콘이 ✕로 바뀌어 같은 버튼으로 다시 닫을 수 있게 합니다.

접근성 측면에서는 버튼에 **이름**(`aria-label`)과 **열림 상태**(`aria-expanded`)가 있어야 합니다. 아이콘 모양만으로는 스크린 리더 사용자가 이 버튼이 무엇을 하는지 알 수 없기 때문입니다.

## 사용하면 좋은 경우

- 목적지가 많아서 화면에 모두 펼쳐 둘 수 없을 때 이를 **모아서 숨길** 때
- 반응형 웹사이트에서 넓은 화면의 상단 메뉴를 좁은 화면에서 **접어 둘** 때
- 앱 바 왼쪽에 Navigation Drawer를 여는 **일관된 진입점**이 필요할 때

## 사용하지 말아야 할 경우

- 목적지가 3~5개뿐일 때. 숨기지 말고 Bottom Navigation이나 탭으로 드러냅니다. 숨긴 메뉴는 덜 쓰입니다.
- 하위 화면에서 ☰를 뒤로 가기 대신 둘 때. 하위 화면의 왼쪽 위에는 뒤로 가기 화살표가 와야 합니다.
- 부가 동작(공유, 삭제 등)을 담는 메뉴로 쓸 때. 그 역할은 Kebab Menu나 Meatball Menu가 맡습니다.
- 아이콘만 두고 접근 가능한 이름 없이 만들 때.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 아이콘 | `menu` (☰) | 표준 아이콘 없음 |
| 위치 | 앱 바 맨 왼쪽(내비게이션 아이콘 자리) | (해당 없음) |
| 여는 대상 | Navigation drawer | (해당 없음) |
| 대체 수단 | (해당 없음) | Tab bar, iPad의 Sidebar 토글 |
| 웹에서의 관례 | 오른쪽 또는 왼쪽 위, 열리면 ✕로 바뀜 | (해당 없음) |

iOS HIG는 숨겨진 내비게이션보다 Tab bar처럼 **늘 보이는 내비게이션**을 권장합니다. 그래서 iOS 기본 앱에서는 ☰ 아이콘을 거의 볼 수 없습니다.
