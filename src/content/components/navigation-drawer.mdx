## 정의

Navigation Drawer는 화면 왼쪽 가장자리에서 밀려 나오는 패널에 앱의 **목적지 목록**을 담은 내비게이션입니다. 보통 앱 바의 ☰(Hamburger Menu) 버튼을 눌러 엽니다.

Material Design 3는 두 종류를 구분합니다. **Modal navigation drawer**는 화면 위를 덮고 스크림으로 뒤쪽을 어둡게 하며, 목적지를 고르거나 바깥을 누르면 닫힙니다. **Standard navigation drawer**는 넓은 화면에서 콘텐츠 옆에 늘 펼쳐져 있습니다. 이 사전의 왼쪽 목록도 모바일에서는 Modal navigation drawer로 동작합니다.

## 사용하면 좋은 경우

- 목적지가 **5개를 넘어서** Bottom Navigation에 다 넣을 수 없을 때
- 메일 앱의 폴더·라벨처럼 목적지를 **묶음별로** 보여 주어야 할 때
- 자주 쓰지는 않지만 어디서든 갈 수 있어야 하는 화면(설정, 도움말 등)을 모아 둘 때

## 사용하지 말아야 할 경우

- 목적지가 3~5개이고 자주 오가야 할 때. 드로어는 한 번 더 눌러야 보이므로 Bottom Navigation이 더 빠릅니다.
- 앱의 **핵심 기능**을 드로어 안에만 둘 때. 숨겨진 메뉴는 발견되기 어렵고 실제로 덜 쓰입니다.
- iOS 앱에서 Android와 똑같은 드로어를 그대로 쓰려 할 때. iOS 사용자에게는 Tab bar가 익숙합니다.
- 드로어 안에 또 다른 드로어나 깊은 단계의 메뉴를 넣으려 할 때.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 공식 명칭 | Navigation drawer (Modal / Standard) | 해당 컴포넌트 없음 |
| 대체 수단 | (해당 없음) | Tab bar, iPad에서는 Sidebar |
| 여는 방법 | 앱 바의 메뉴 아이콘, 화면 왼쪽 가장자리에서 끌기 | (해당 없음) |
| 닫는 방법 | 목적지 선택, 스크림 탭, 왼쪽으로 끌기, 뒤로 가기 | (해당 없음) |
| 활성 항목 | 알약 모양 배경으로 강조 | Sidebar에서 선택 행 강조 |

iOS HIG에는 왼쪽에서 밀려 나오는 드로어가 없습니다. 최상위 목적지는 Tab bar로, iPad처럼 넓은 화면에서는 Sidebar로 보여 주도록 권장합니다. Material도 최근에는 넓은 화면에서 Navigation rail을 펼친 형태를 권장하는 쪽으로 바뀌고 있습니다.
