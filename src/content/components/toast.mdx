## 정의

Toast는 "임시 저장했습니다"처럼 짧은 알림 문구를 화면 아래쪽에 잠깐 띄웠다가 스스로 사라지게 하는 메시지입니다. 토스터에서 빵이 튀어 올랐다 내려가는 모습에서 이름이 왔습니다.

Toast에는 **버튼이 없고** 누를 수도 없습니다. 사용자의 작업을 방해하지 않고 정보만 전합니다. 원래는 Android 플랫폼이 제공하는 API(`android.widget.Toast`)로, 표시 시간은 짧게(`LENGTH_SHORT`, 약 2초)와 길게(`LENGTH_LONG`, 약 3.5초) 두 가지입니다.

## 사용하면 좋은 경우

- 작업이 끝났다는 **가벼운 확인**만 주면 될 때 (저장됨, 복사됨, 전송됨)
- 사용자가 놓쳐도 아무 문제가 없는 정보일 때
- 앱 화면 밖에서 일어난 일을 짧게 알려야 할 때 (Android 시스템 Toast)

## 사용하지 말아야 할 경우

- 실행 취소나 다시 시도 같은 **동작**이 필요할 때. 버튼을 담을 수 있는 Snackbar를 씁니다.
- 오류처럼 사용자가 **반드시 읽어야** 하는 정보일 때. 2초 만에 사라져 놓칠 수 있습니다. Dialog나 화면 안 오류 문구를 씁니다.
- 문구가 길 때. 짧은 시간 안에 다 읽을 수 없습니다.
- 여러 Toast를 짧은 간격으로 연달아 띄울 때

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 공식 명칭 | 디자인 시스템 컴포넌트는 아님 (Android 플랫폼 API `Toast`) | 해당 컴포넌트 없음 |
| 동작 버튼 | 없음 (버튼이 필요하면 Snackbar) | (해당 없음) |
| 표시 시간 | `LENGTH_SHORT` 약 2초, `LENGTH_LONG` 약 3.5초 | (해당 없음) |
| 생김새 | 화면 아래 가운데의 둥근 알약 모양 | 앱마다 직접 만든 배너나 HUD |

Material Design 3의 공식 컴포넌트는 Snackbar이고, Toast는 Android 운영체제가 제공하는 API입니다. Android 12부터는 Toast가 두 줄로 제한되고 앱 아이콘이 함께 표시됩니다.

iOS에는 표준 Toast가 없습니다. 그래서 많은 iOS 앱이 비슷한 배너를 직접 만들어 씁니다. 웹 서비스에서는 Snackbar와 Toast를 구분하지 않고 모두 "토스트"라고 부르는 경우가 많습니다. 이 사전에서는 **동작 버튼이 있으면 Snackbar, 없으면 Toast**로 구분합니다.
