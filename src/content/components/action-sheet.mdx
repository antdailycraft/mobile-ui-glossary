## 정의

Action Sheet는 사용자가 어떤 작업을 시작했을 때 그 작업에 대한 **선택지 목록**을 iPhone 화면 아래에서 띄우는 iOS 컴포넌트입니다. 항목들은 둥근 모서리의 그룹 안에 세로로 쌓이고, **취소** 버튼은 따로 떨어진 그룹으로 맨 아래에 놓입니다.

UIKit에서는 `UIAlertController`의 `actionSheet` 스타일로, SwiftUI에서는 `confirmationDialog`로 만듭니다. 삭제처럼 되돌릴 수 없는 항목은 빨간색(파괴적 스타일)으로 표시합니다.

## 사용하면 좋은 경우

- 사용자가 버튼을 눌러 **직접 시작한** 작업에 몇 가지 방식이 있을 때 (사진 저장, 앨범에 추가, 삭제)
- 삭제처럼 파괴적인 작업 전에, 그 작업과 취소 중 하나를 고르게 할 때
- 선택지가 2~5개 정도로 짧은 문구로 표현될 때

## 사용하지 말아야 할 경우

- 사용자가 요청하지 않은 정보를 알리거나 오류를 보여 줄 때. 이럴 때는 Alert(Dialog)를 씁니다.
- 선택지가 많거나 아이콘·설명이 필요할 때. Sheet나 새 화면이 더 적합합니다.
- 취소 버튼을 빼거나 다른 항목 사이에 섞을 때. 취소는 항상 맨 아래에 따로 둡니다.
- Android 앱에서 그대로 쓸 때. Material에서는 Modal Bottom Sheet가 같은 역할을 합니다.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 공식 명칭 | 해당 컴포넌트 없음 (Modal Bottom Sheet로 대체) | Action Sheet |
| 생김새 | 화면 아래에 붙은 시트, 아이콘과 함께 목록 표시 | 화면 아래에 떠 있는 둥근 그룹, 텍스트 중심 |
| 취소 | 스크림 탭, 아래로 끌기, 뒤로 가기 | 분리된 "취소" 버튼 (iPhone에서는 바깥을 눌러도 닫히지 않음) |
| 파괴적 항목 | 별도 스타일 규정 없음 | 빨간색 `destructive` 스타일 |
| 큰 화면 | 시트 또는 메뉴 | iPad에서는 버튼 옆에 팝오버로 표시 |

iPhone의 UIKit Action Sheet는 바깥 영역을 눌러도 닫히지 않으므로 사용자가 "취소" 버튼으로 명시적으로 닫아야 합니다. iPad에서 팝오버로 뜰 때는 취소 버튼이 사라지고, 팝오버 바깥을 누르면 취소로 처리됩니다.

iOS 앱에서 Action Sheet를 쓰는 자리라면, Android 앱에서는 대개 동작 목록을 담은 Modal Bottom Sheet를 씁니다. 같은 기능이라도 플랫폼에 맞는 형태로 바꿔 주면 각 플랫폼 사용자에게 익숙합니다.
