## 정의

Caret은 **▼, ▲처럼 속이 채워진 작은 삼각형** 아이콘입니다. 선으로만 그리는 [Chevron](#chevron-down)과 모양이 다르고, 쓰임새도 조금 다릅니다. 웹에서는 Bootstrap의 드롭다운 버튼, Font Awesome의 `caret-down` 아이콘처럼 Chevron과 Caret을 별개의 이름으로 구분합니다.

Caret Down은 주로 세 가지 뜻으로 씁니다.

- **드롭다운**: 값이 들어 있는 입력란이나 버튼 끝에 붙어, 누르면 선택지 목록이 열린다는 것을 알립니다. Material의 드롭다운 메뉴(exposed dropdown menu)가 대표적입니다.
- **정렬 방향**: 표 머리글에서 ▲는 오름차순, ▼는 내림차순을 나타냅니다.
- **트리 펼침**: 파일 탐색기나 macOS의 disclosure triangle처럼 ▶이 ▼로 돌아가며 하위 항목을 펼칩니다.

## 사용하면 좋은 경우

- 폼에서 **여러 선택지 중 하나를 고르는** 입력란 (드롭다운, select)
- 표나 목록의 머리글에서 **현재 정렬 기준과 방향**을 보여 줄 때
- 폴더 구조처럼 **계층이 있는 목록**에서 하위 항목을 펼칠 때
- 텍스트 옆에 붙는 아주 작은 표시가 필요할 때. 삼각형은 작아도 형태가 또렷합니다.

## 사용하지 말아야 할 경우

- 아코디언이나 "더 보기"처럼 같은 화면의 내용이 펼쳐지는 곳. 이때는 [Chevron Down](#chevron-down)이 더 일반적입니다.
- 한 화면 안에서 드롭다운에는 ▼를, 아코디언에도 ▼를 써서 **두 동작을 구분할 수 없게** 될 때
- iOS 앱의 선택 버튼. iOS는 삼각형 대신 위아래 Chevron(`chevron.up.chevron.down`)을 씁니다.
- 정렬 상태를 아이콘으로만 알릴 때. 표 머리글에 `aria-sort`를 지정해 스크린 리더에도 전달합니다.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 아이콘 이름 | `arrow_drop_down`(▼), `arrow_drop_up`(▲), `arrow_right`(▶) | SF Symbols `arrowtriangle.down.fill` 등 |
| 드롭다운 표시 | 드롭다운 메뉴 끝에 ▼, 열리면 ▲ | 팝업 버튼 끝에 `chevron.up.chevron.down`(위아래 Chevron) |
| 트리 펼침 | 표준 컴포넌트 없음 | macOS의 disclosure triangle(▶ → ▼), iOS는 Chevron 사용 |
| 정렬 방향 | 표 머리글의 화살표나 삼각형 | 표준 규정 없음 |

Material은 드롭다운에 Caret(▼)을, 펼침에 Chevron(⌄)을 써서 둘을 구분합니다. iOS는 대부분의 자리에 Chevron을 쓰고, 채워진 삼각형은 주로 macOS의 disclosure triangle에 남아 있습니다.

**접근성 주의:** 드롭다운 버튼에는 `aria-haspopup="listbox"`와 `aria-expanded`를, 정렬 머리글에는 `aria-sort`를 지정합니다. 삼각형 아이콘 자체는 장식으로 숨깁니다.
