## 정의

Tooltip은 아이콘 버튼처럼 이름이 화면에 드러나지 않는 요소에 **짧은 설명**을 덧붙이는 작은 말풍선입니다. 데스크톱에서는 마우스를 올렸을 때, 키보드에서는 포커스가 들어왔을 때, 터치 화면에서는 **길게 눌렀을 때** 나타나고, 잠시 뒤 스스로 사라집니다.

Material Design 3는 두 종류로 나눕니다. **Plain tooltip**은 한 줄짜리 이름만 보여 줍니다. **Rich tooltip**은 제목, 본문, 동작 버튼을 담을 수 있고, 사용자가 직접 닫을 때까지 남아 있을 수 있습니다.

## 사용하면 좋은 경우

- 아이콘만 있는 버튼의 **이름**을 알려 줄 때 (예: 공유, 저장, 즐겨찾기)
- 용어나 수치에 짧은 **보충 설명**을 붙일 때 (rich tooltip)
- 화면을 복잡하게 만들지 않고, 필요한 사람만 설명을 찾아보게 하고 싶을 때

## 사용하지 말아야 할 경우

- 작업에 **꼭 필요한 정보**를 툴팁에만 넣을 때. 터치 화면에서는 툴팁을 띄우는 방법(길게 누르기)을 모르는 사용자가 많습니다.
- 이미 화면에 보이는 글자를 **그대로 반복**할 때. 텍스트 라벨이 있는 버튼에는 툴팁이 필요 없습니다.
- 오류 메시지나 입력 형식 안내처럼 사용자가 계속 봐야 하는 내용일 때. 입력 필드 아래 도움말 문구로 보여 줍니다.
- 툴팁 안에 링크나 버튼을 여러 개 넣어 작은 대화상자처럼 쓸 때. Dialog나 Bottom Sheet가 적합합니다.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 공식 명칭 | Plain tooltip, Rich tooltip | 아이폰에는 해당 컴포넌트 없음 (iPadOS 포인터·macOS에서는 Help tag) |
| 표시 방법 | hover, 포커스, 길게 누르기 | 포인터를 올렸을 때 (iPadOS 포인터, Mac) |
| 사라지는 방식 | plain은 잠시 뒤 자동, rich는 직접 닫을 수 있음 | 포인터가 벗어나면 사라짐 |
| 터치 대안 | 길게 누르기 | 텍스트 라벨, 길게 눌러 여는 컨텍스트 메뉴, TipKit의 팁 |

iOS에서는 길게 누르기를 주로 **컨텍스트 메뉴**에 씁니다. 그래서 아이폰 앱은 아이콘에 툴팁을 붙이기보다, 의미가 분명한 SF Symbols 아이콘과 텍스트 라벨을 함께 쓰는 쪽을 권장합니다. 기능을 처음 알려 주는 용도라면 iOS 17부터 제공되는 **TipKit**의 팝오버 팁을 씁니다.

**접근성 주의:** 툴팁 내용은 `aria-describedby`로 대상 요소에 연결해 스크린 리더가 읽게 합니다. 키보드 포커스로도 나타나야 하고, Esc로 닫을 수 있어야 합니다.
