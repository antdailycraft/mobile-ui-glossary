## 정의

Modal Bottom Sheet는 화면 아래 가장자리에 붙어 올라오는 표면(surface)입니다. 뒤쪽 화면은 **스크림**(scrim)으로 어둡게 덮이고, 시트를 닫기 전까지 뒤쪽 화면은 조작할 수 없습니다.

위쪽의 **드래그 핸들**을 아래로 끌거나, 스크림을 누르거나, 뒤로 가기를 하면 닫힙니다. 휴대폰에서는 엄지가 닿기 쉬운 아래쪽에 선택지를 모아 보여 줄 수 있어서, 메뉴나 간단한 다이얼로그를 대신해 많이 씁니다.

## 사용하면 좋은 경우

- 현재 화면의 맥락을 유지한 채 **추가 동작 목록**을 보여 줄 때 (공유, 복사, 수정, 삭제 등)
- 필터·정렬처럼 **짧은 설정**을 받고 바로 원래 화면으로 돌아와야 할 때
- 선택지가 많아서 작은 팝업 메뉴에 다 들어가지 않을 때
- 한 손 조작이 중요한 모바일 화면에서 **엄지 영역**에 조작부를 두고 싶을 때

## 사용하지 말아야 할 경우

- 사용자가 시트와 뒤쪽 화면을 **번갈아 보며** 작업해야 할 때. 이럴 때는 뒤쪽 조작을 막지 않는 Standard Bottom Sheet를 씁니다.
- 되돌릴 수 없는 작업을 **확인**받아야 할 때. 주의를 더 강하게 끄는 Dialog가 적합합니다.
- 내용이 길어서 시트가 화면 대부분을 차지하게 될 때. 새 화면으로 이동하는 편이 낫습니다.
- 시트 위에 또 다른 시트를 겹쳐 띄워야 할 때. 겹친 시트는 어느 것을 닫는지 헷갈리게 만듭니다.

## 플랫폼별 차이

| 항목 | Material Design 3 | iOS HIG |
|---|---|---|
| 공식 명칭 | Bottom sheet (modal) | Sheet |
| 높이 | 내용 높이만큼, 최대 화면의 대부분 | detent로 지정 (`medium`은 화면 절반, `large`는 거의 전체) |
| 핸들 | Drag handle (선택 사항, 권장) | Grabber (detent가 여러 개일 때 표시) |
| 닫기 | 아래로 끌기, 스크림 탭, 뒤로 가기 | 아래로 끌기, 취소/완료 버튼 |
| 뒤쪽 화면 | 스크림으로 어둡게 덮음 | 뒤쪽 화면이 살짝 작아지며 뒤로 물러남 (large) |

iOS에서 화면 아래에 선택지 목록만 띄우는 경우는 Sheet가 아니라 **Action Sheet**를 씁니다. Material의 "동작 목록을 담은 Modal Bottom Sheet"에 해당하는 iOS 컴포넌트는 Action Sheet라고 보면 됩니다.
